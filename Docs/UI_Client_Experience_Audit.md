## Cross-Cutting Source Notes

- `App.xaml` contains the default `ComboBox` template with `PopupAnimation="Fade"` and global table/control styles. This is the likely place to remove unnecessary animation and enforce consistent dark/light foregrounds.
- `FactoryHmiLayout.xaml` already provides table, scroll, trimming, and HMI layout styles, but individual pages still use fixed widths that defeat the system-level layout contract.
- `MainWindow.xaml` carries the largest shell-wide risk: header chrome, readiness chips, active alarms, title toolbar, navigation, loading overlay, and footer all compete for the same 1920x1080 viewport.
- The highest-risk tables are in `ReviewView.xaml`, `ReportsView.xaml`, `LibraryView.xaml`, `AIModelTestView.xaml`, `MonitorView.xaml`, and `SpcView.xaml`.

## Staged Implementation Plan

1. Capture a current screenshot baseline for every major page at 1920x1080 with 100%, 125%, and 150% DPI assumptions, including English and Korean Settings.
2. Fix P0 correctness and theme defects first: calibration combo display, Settings dark/light contrast leak, Export & Trace clipping, and Defect Review queue headers.
3. Compact the shell: reduce vertical chrome, collapse empty alarms, stabilize readiness chips, keep active navigation visible, and protect footer/warning spacing.
4. Harden shared styles: table column/header policy, combo/date picker sizing, tab theme consistency, disabled-control contrast, trimming-with-tooltip, and no-animation defaults.
5. Rework dense pages into clearer subviews: Reports, Recipe Rules, AI/Models, Run Inspection diagnostics, Golden Compare findings, and Settings categories.
6. Strengthen evidence boundaries: calibration, 3D profile, hardware readiness, mock/demo labels, and simulated-source claims must remain visible without crowding primary actions.
7. Verify with automated and manual gates: HMI layout audit JSON/HTML, navigation performance artifact, screenshot review, long-string/Korean data fixtures, empty/error/loading states, and a final client-package visual pass.
