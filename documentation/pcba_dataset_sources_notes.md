# PCBA Dataset Source Notes

## Purpose

DeepPCB is being used to test the database structure, but the project also needs PCBA-specific examples for assembled-board inspection.

## PCBA defect types to prioritize

- Missing Component
- Misalignment
- Tombstone
- Polarity Error
- Solder Bridge
- Insufficient Solder
- Excess Solder
- Cold Joint
- Contamination
- Connector Pin Height
- Shield Can Gap

## Required sample types

- Defective examples
- Good / normal examples
- Hard-negative examples
- Borderline acceptable examples
- Images from different lighting conditions
- Images from different board/component types

## Notes

The next dataset source should better represent assembled PCBA inspection rather than only bare PCB surface defects.
