Recommended Navigation Route

This prototype is organized like a compact AOI review station: start from the queue, disposition defects, search reference samples, check recipe thresholds, review SPC/database health, then export customer or engineering evidence.

1

Production Overview

Use this as the operator landing page. It summarizes possible escapes, false calls, annotation coverage, database status, and current inspection program.

2

Review / Disposition

Review AI/ground-truth mismatches, compare top similar samples, and record final dispositions such as Verified NG, Verified OK, False Call, or Possible Escape.

3

Defect Image Library

Search by Sample ID, defect code, RefDes, lot, severity, review status, and model version. Use this when users need evidence or reference cases.

4

Inspection Recipe

Check recipe identity, ROI rules, component-level inspection items, and threshold settings before explaining why a sample was judged OK or NG.

5

SPC / Traceability

Use data-health and SPC previews to identify false-call components, weak defect classes, broken image references, and traceability gaps.

6

Reports / Utilities

Export CSVs, annotated images, review evidence, and database backups for customer validation or internal QC documentation.
